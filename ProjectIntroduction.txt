Project Introduction
====================

一、项目简介

1. 本项目由 Django 担任后端（文件夹 /FindAnimals），微信小程序担任前端（文件夹 /fztujian/fztujian），
   主要功能是用户拍照上传、评论相关动物信息，管理员管理相关内容。
2. 需要使用 HTTPS 沟通前后端，域名 wulara.top，公有IP 47.103.53.186，私有IP 172.24.28.193。
3. 使用 Nginx 作为反向代理，使项目可以长期运行。
4. 项目 GitHub 地址：https://github.com/shylara-zhou/FindAnimals/tree/main/FindAnimals

二、项目结构

后端：FindAnimals/FindAnimals/
  - manage.py, settings.py, urls.py, wsgi.py
  - 数据库：db_v2.sqlite3（SQLite）
  - 应用模块：accounts（用户）、animalsdata（动物数据、公园、评论等）

前端：FindAnimals/fztujian/fztujian/
  - 微信小程序标准文件 (.js, .json, .wxml, .wxss)

媒体文件：FindAnimals/media/

虚拟环境：FindAnimals/new_venv/

三、启动方式

# 进入项目根目录
cd /home/admin/FindAnimals

# 激活虚拟环境并启动 Django 服务（后台运行，日志输出到 django.log）
source new_venv/bin/activate && nohup python FindAnimals/manage.py runserver 0.0.0.0:8000 > django.log 2>&1 &

# 启动后可以用以下命令查看日志
tail -f django.log

四、停止服务

# 查找正在运行的 Django 进程
ps aux | grep manage.py

# 杀掉进程（替换 PID 为实际进程号）
kill <PID>

# 或者一键杀掉所有 Django runserver 进程
pkill -f "manage.py runserver"

五、Nginx 配置

配置文件路径：/etc/nginx/conf.d/django.conf

重启 Nginx：
  sudo systemctl reload nginx    # 重新加载配置
  sudo systemctl restart nginx   # 重启 Nginx

六、HTTPS 配置

证书已通过 Certbot 自动配置在 /etc/nginx/conf.d/django.conf 中。
自动续期已由 Certbot 定时任务处理。

手动测试 HTTPS：
  curl -I https://wulara.top

七、快速运维检查清单

# 1. 检查 Django 是否在运行
ss -tlnp | grep 8000

# 2. 测试后端是否正常
curl http://127.0.0.1:8000/

# 3. 测试 Nginx 代理是否正常
curl -I http://127.0.0.1/

# 4. 测试 HTTPS 是否正常
curl -I https://wulara.top

# 5. 查看 Django 日志
tail -100 /home/admin/FindAnimals/django.log
